# File 25 — Sabri Public UI, Profile Timeline and Visual Experience

Production-grade WordPress module for the **Sabri Social Homeopathy Platform**.

This repository is governed by the Founder-approved File 25 specification and will provide:

- unified public profile presentation for the Founder, verified doctors, and permitted members;
- a federated, rebuildable author-centric public timeline without duplicating native content ownership;
- reusable public content cards and states;
- responsive, accessibility-oriented, privacy-aware visual experience;
- safe integration with Files 00, 03, 20, 21, 22, 23, and 24;
- migration, rollback, diagnostics, and comprehensive QA.

## Governing architecture

File 20 remains the global application-shell owner. File 21 remains the Home/News publication owner. File 24 remains the security, privacy, compliance, and resilience owner. File 25 is the public presentation and profile-timeline layer.
