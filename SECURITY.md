# Security Policy

## Ownership boundary

File 24 remains the canonical owner of platform security, privacy, compliance, incident management, and resilience. File 25 consumes those policies and implements secure public rendering.

## File 25 guarantees

- Server-side public-field allowlists.
- Privacy-first profile visibility.
- Forced contact privacy for minors through the authoritative File 00 contract.
- REST permission callbacks and strict parameter sanitation.
- Canonical native-object pointers rather than duplicated content bodies.
- Context-aware escaping in public templates.
- Fail-closed behavior when required runtime dependencies are unavailable.
- Safe Mode that disables profile overrides without deleting native data.

## Reporting

Do not disclose vulnerabilities in public issues. Report them through the platform's authorized security channel. Never include identity documents, patient records, secrets, access tokens, or production credentials in reports.
