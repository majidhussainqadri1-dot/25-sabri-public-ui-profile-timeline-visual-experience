# File 25 Accessibility Contract

## Scope

File 25 owns public visual accessibility for Founder, Doctor and permitted Member profiles, Profile Timeline, public cards, states and reusable visual components. File 20 remains the structural shell owner; native domain modules remain the owners of their data and actions.

## Source requirements

The source candidate must preserve keyboard operability, visible focus, semantic landmarks/headings, touch targets, reduced-motion handling, forced-colors resilience, RTL/LTR-safe presentation and usable zoom/reflow through 400%. Accessibility behavior must not reveal private profile, minor, clinical, message, verification-evidence or patient data.

## Acceptance evidence

Source code and automated checks are preparation evidence only. Human/browser evidence is still required on the exact staging artifact for keyboard order, screen-reader semantics, 200%/400% zoom, reduced motion, forced colors, mobile/tablet/desktop widths and Urdu/Arabic RTL with English LTR islands.

**Current status:** source-prepared; Hostinger-equivalent staging acceptance pending. No production/live claim is made.
