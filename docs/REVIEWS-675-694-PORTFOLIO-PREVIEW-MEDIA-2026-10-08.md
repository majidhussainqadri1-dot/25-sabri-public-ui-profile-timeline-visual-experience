## Corrections

### File 03 cover focal truth

File 25 already parsed File 03 `focal_x`/`focal_y` but discarded those values before rendering. The canonical owner coordinates now reach the public cover through bounded CSS custom properties. The administrator center/top/bottom/left/right preference is used only when File 03 has no focal coordinates.

### Profile Hero completeness

The hero now includes a bounded brief introduction when a public biography exists and a truthful status-banner surface for eligible public lifecycle/degraded states. It does not fabricate online status, verification, availability or success.

### RTL owner preview

The private owner/admin View-as-Public family now includes an explicit `rtl` mode. The preview changes direction/presentation only, stays noindex and does not widen the public data projection.

### Portfolio Timeline

The author-centric Timeline is no longer effectively post-only. Approved, enabled and available File 06 Knowledge, File 10 Video, File 11 Reels and File 12 PDF public projections are normalized into File 25's federated Timeline. Normal profile-section card limits remain 24; timeline retrieval may request a bounded pool up to 500 without creating a second native data store.

File 18 Marketplace remains a profile section rather than being misclassified as portfolio activity.

### Complete §46 provider surface

A new `Timeline_Provider_Plan_Contract` extends the existing compatibility floor without silently breaking previously reviewed providers. Built-in File 21, WordPress fallback and File 06/10/11/12 portfolio adapters provide normalize/canonical/visibility/actions/metrics/correction/sync/health methods in addition to the existing identity/query methods. System Check reports legacy compatibility-floor providers instead of calling them complete.

### Audited time-bounded pinning

A non-zero `pin_weight` now requires actor, reason, audit reference, surface, start and end metadata. Future or expired pins have zero effective pin weight. Audit metadata is internal and is removed from public DTO output.
